# Kernel Patch Submission Guide

## Quick Start

```bash
./generate-patch.sh
```

This script:
1. Verifies git user.name/email are configured (required for Signed-off-by)
2. Clones Takashi Iwai's sound.git for-next branch
3. Applies changes to sound/pci/hda/patch_realtek.c
4. Creates a properly formatted commit
5. Generates patch via git format-patch
6. Runs checkpatch.pl

## Pre-Submission Checklist

- [ ] `git config user.name` is your real name
- [ ] `git config user.email` is your real email
- [ ] `./generate-patch.sh` completed successfully
- [ ] `checkpatch.pl` reports no errors
- [ ] Patch applies cleanly to current for-next
- [ ] Reviewed the generated patch manually
- [ ] Tested on actual hardware (already done in Phase 2)

## Sending the Patch

Configure git send-email (one time):
```bash
git config --global sendemail.smtpserver smtp.yourprovider.com
git config --global sendemail.smtpserverport 587
git config --global sendemail.smtpencryption tls
git config --global sendemail.smtpuser your@email.com
```

Send:
```bash
git send-email \
  --to="tiwai@suse.de" \
  --cc="alsa-devel@alsa-project.org" \
  0001-ALSA-hda-realtek-enable-dual-DAC-on-Gigabyte-*.patch
```

## Patch Requirements (kernel.org standards)

1. **Unified diff format** - generated by git format-patch
2. **Signed-off-by** - certifies Developer Certificate of Origin
3. **No more than 75 chars** per line in commit message body
4. **Subsystem prefix** - `ALSA: hda/realtek:` for this file
5. **checkpatch.pl clean** - no errors, minimal warnings

## What to Expect

1. Patch appears on alsa-devel mailing list archives
2. Takashi Iwai reviews (typically within days to a week)
3. May request changes (respond as reply to thread)
4. If accepted: sound.git -> linux-next -> mainline

## Post-Merge Verification

Once in a released kernel:
```bash
journalctl -k | grep -i "alc1220.*fixup"
# Should show: picked fixup ... ALC1220_FIXUP_GB_AORUS_NO_AUTOMUTE

cat /proc/asound/card*/codec* | grep -A5 "Node 0x1b"
# Connection line should show 0x0d* (not 0x0c*)
```
